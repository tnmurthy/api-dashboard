╚══════════════════════════════════════════════════════════════════════════════════════════════════╝

FLOW 1: Configure via Terminal
  1. User clicks Dashboard tab
  2. User types: config openclaw --primary gpt-4-turbo --fallback claude-3-sonnet
  3. Terminal shows: ✓ OpenClaw configured
  4. Config view updates automatically

FLOW 2: Configure via Visual UI
  1. User clicks Configure tab
  2. User selects model from dropdown
  3. Command preview updates in real-time
  4. User clicks Apply
  5. Button shows: ✓ Applied (2 seconds)
  6. Config saved to LocalStorage

FLOW 3: Export Configuration
  1. User types: export openclaw (in terminal)
     OR clicks "Export All" button (in config view)
  2. JSON file downloads automatically
  3. Terminal/Button shows confirmation
